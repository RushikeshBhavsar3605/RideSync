// Architecture Note

This is a backend architecture demo, not a UI/UX showcase. RideSync is engineered for production correctness — distributed microservices with strict inter-service integrity, async event streaming, and end-to-end observability.

The live demo runs a simplified HTTP build on Render's free tier. The production architecture uses gRPC + Protocol Buffers for typed inter-service contracts, Kubernetes for orchestration, RabbitMQ for async event streaming, and OpenTelemetry + Jaeger for distributed tracing. These are intentionally omitted here — Render's infrastructure does not support them.
